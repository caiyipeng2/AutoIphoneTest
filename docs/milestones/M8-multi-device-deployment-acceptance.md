# M8 多设备部署链路切片验收

## 本切片范围

本切片完成 M8 Task 2 的 API 与部署编排器基础能力：

- `deviceSerials` 支持 1-4 个唯一 Android 设备串号。
- 旧的单设备 `deviceSerial` 请求保持兼容，且两种字段不能同时传入。
- 一个逻辑部署任务为每个目标创建独立 `deployment_devices` 记录。
- 安装、预检、身份校验和启动按 serial 独立运行，最多四个目标并发。
- 单个设备身份校验失败不会覆盖其他设备的成功结果。
- 重试只重新执行失败设备；已完成设备保持完成状态。
- 聚合状态由每个设备状态推导，设备级失败信息保留在 `devices` 返回值中。

# M10 Task 4：Results 历史控制台验收记录

## 本切片范围

- Results 页面从只读接口 `GET /api/results?limit=50` 读取终态会话历史。
- 以表格展示运行 ID、包体、设备/UID、会话状态、HTML/ZIP 输出状态和更新时间。
- 支持在已加载历史上按会话、包体、设备序列号或 UID 搜索。
- 支持按 `FINISHED`、`FAILED`、`INTERRUPTED` 过滤，并提供重新读取入口。
- 覆盖加载中、接口失败、无历史和筛选无结果四类可见状态；移动宽度下表格保持横向滚动。

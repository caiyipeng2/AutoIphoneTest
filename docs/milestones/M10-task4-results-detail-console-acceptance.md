# M10 Task 4：Results 单条详情控制台验收记录

## 本切片范围

- 历史表格中的运行 ID 提供可访问的“查看报告”入口。
- 点击后只读读取 `GET /api/results/:runId`，不创建会话、不派发动作、不改变设备状态。
- 详情视图展示运行状态、Unity 包名、Epoch、设备角色、设备 UID、HTML/ZIP 输出状态、哈希占位和最终化尝试状态。
- 支持从详情返回历史列表；详情读取失败时保留明确错误和返回入口。
- 详情布局在窄屏下改为单列，长串号和哈希不会撑破页面。

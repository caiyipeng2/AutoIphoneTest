# M10 Task 4：Results 最终化重试控制台验收记录

## 本切片范围

- Results 详情页在 `FINALIZATION_FAILED` 或 `INTERRUPTED` 状态显示“重试报告生成”。
- 每次点击生成新的幂等键，调用既有 `POST /api/results/:runId/retry-finalization`，不触发设备动作或游戏操作。
- 重试期间按钮进入明确的忙碌/禁用状态；成功后用服务端返回结果刷新详情并移除重试入口。
- 服务端拒绝在动作附近以 `role="alert"` 展示，保留重试入口供用户恢复。
- 桌面和窄屏布局均保持操作区稳定，复用现有 Lucide 图标和按钮样式。

## 交付边界

本切片只完成控制台重试交互和错误恢复反馈。实际运行时的最终化执行器尚未接入 Results 服务，因此当前后端未配置执行器时仍会返回 `503`；本按钮不会伪造成功，也不会重放设备动作。当前改动未提交或推送，等待用户验收确认。

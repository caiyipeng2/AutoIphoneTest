# Android device onboarding

Install Android platform-tools and enable USB debugging on each phone. Accept the RSA prompt on the phone, then confirm the device is `device` (not `unauthorized`) in the Devices page. The portable package uses its bundled `scrcpy` `adb.exe` by default.

Select one to four online devices. A device can be removed and rejoined before a session starts. Rejoining does not auto-replay actions; the operator must explicitly retry an action after reviewing the incident timeline.

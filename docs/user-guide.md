# User guide

1. Extract the release directory to an E-drive folder without changing its internal layout.
2. Start `TestCenterLauncher.exe`. Choose **启动控制面** and then **打开控制台**.
3. In **设备**, select the connected Android phones. One to four devices may be selected; the first selected device is the leader and the rest follow the same action stream.
4. In **应用**, import an APK/APKS/AAB or register an already installed package. The game package is `Idle Weapon Shop Tycoon`; the UID shown by the console is derived from each device ID.
5. In **会话**, select the build, devices, and failure policy. Start the run, operate the leader, and inspect the live device views and action acknowledgements.
6. In **结果**, open the immutable report. HTML is the default export; Excel, PDF, and JUnit can be requested from the export menu.

The console stores runtime data under `data`. Keep that directory on the same drive as the extracted release and use the Storage page before cleanup.

# v1.0.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare and publish the verified Unity Multi-Device Test Center `v1.0.0` release.

**Architecture:** Version metadata and release documentation stay in Git; large portable binaries remain on E: and are attached as release assets. Local gates run before the main commit, the annotated tag is created only after the commit is pushed and remote access is confirmed, and GitHub Release creation is the final external operation.

**Tech Stack:** npm workspaces, PowerShell, .NET 9 Launcher, portable ZIP/manifest, Git annotated tags, GitHub CLI/API.
